### 🔐 VaultGit — Encrypted Credential Manager

<p align="center">
  <img src="https://raw.githubusercontent.com/GonzaloCS01/VaultGit/main/assets/vaultgit-logo.png" alt="VaultGit logo" width="120">
</p>

A local encrypted credential manager for Windows built with Python.

**Highlights**
- Argon2id password-based key derivation
- XChaCha20-Poly1305 authenticated encryption
- Encrypted backups and recovery
- Automatic inactivity locking
- Progressive unlock throttling
- Private `%LOCALAPPDATA%` storage
- Reproducible Windows release
- 69 automated tests passing
